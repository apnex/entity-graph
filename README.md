# entity-graph

Keep an in-memory graph of declared references between typed entities, dated by the store position it reflects, and plan every edit with its cascades, reactions, result invariants and inverse into one atomic change.

**Status: no code yet.**\
Its vision is drafted and awaits ratification, and its contract is drafted; its design is owed.

- `VISION.md` - why it exists, and what it will never be.
- `CONTRACT.md` - what a consumer can depend on, one capability per row.
- `docs/DECISIONS.md` - the rulings about this component.

It belongs to the component set composed by zorg (`apnex/zorg`, `BL33`) and drawv2 (`apnex/drawv2`), and is private until its first working code.
